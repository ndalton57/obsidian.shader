## Contribution guide

Tachyon is a personal fork of [Photon](https://github.com/sixthsurge/photon) by
SixthSurge. Bug fixes, `block.properties` additions, and translations are
welcome.

- For larger features or stylistic changes, please open an issue to discuss it
  first before you start working — this avoids the disappointment of spending a
  long time on something that may not end up being merged.
- If a change really belongs to the original Photon rather than this fork,
  consider contributing it [upstream](https://github.com/sixthsurge/photon)
  instead.
- Please follow the [style guide](docs/style_guide.md) for code contributions.
